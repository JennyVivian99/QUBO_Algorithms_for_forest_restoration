# QUBO and CBQP algorithms for forest restoration #
Quadratic Unconstrained Binary Optimization (QUBO) and Constrained Binary Quadratic Program (CBQP) algorithms for the optimization of forest restoration plans.
Content of the different folders:
#
- CBQP_Gurobi: Classical form of the algorithms (simple and complex forms), executed in Gurobi. The sensitivity analysis done for the complex form is also present.
- Matrix_Q: Example of the creation of a matrix Q, which is the file type needed for the implementation of the algorithms in real quantum computers. This is only an example, as the matrices Q needed for the QUBO Qiskit simulations are created within the process in each code.
- QUBO_Gurobi: Quantum-ready form of the algorithms (simple and complex forms), executed in Gurobi.  The sensitivity analysis done for the complex form is also present.
- QUBO_Qiskit: Quantum-ready form of the algorithms (simple and complex forms), executed in Qiskit.
